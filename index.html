User guide

Varians compares ALTO XML transcriptions against a reference witness and lets you review the readings against the facsimiles.

1. Import and align witnesses

  1. Under Work & witnesses, select the ALTO files for the reference witness and enter its name. Use Add a witness for each other witness. You can compare up to ten witnesses, including the reference. Use Remove witness to take a witness out of the project.
  2. To see the handwriting alongside the text, select the corresponding page images for each witness. Matching filenames help Varians link images to their ALTO files.
  3. The comparison starts as soon as the reference and another witness are available. Use Align text units to recalculate. Save a project copy before a recalculation if you have reviewed readings.

2. Review the collation

  • Pair shows the reference and one selected witness. All witnesses keeps the reference on the left and lets you scroll through the other witnesses. Line by line shows one unit at a time, with arrows to navigate.
  • Yellow marks a variant awaiting a decision. Keep turns it green and includes it in the TEI apparatus. Ignore turns it grey and strikes it through. Use Next pending variant to continue reviewing.
  • Use Edit text to correct a reading and Adjust alignment to split or move a fragment. When a witness reading spans several fragments, its controls are under Review details. The check mark appears after every variant in that witness card has a decision.
  • Click a facsimile crop to open the whole page. When the ALTO provides coordinates, a red outline identifies the source line.

3. Save or export

  • Save project downloads a session file for Open project. It records the work and the names of the local images, which you can select again after opening the file. Reloading the same browser tab normally restores the local session.
  • Use Export → TEI to choose prose, poetry or drama for the whole text or by interval. Use Title lines to mark reference lines for export as <head>.
  • Use Export → JSON to reuse readings, ALTO references and review decisions in other tools.

Varians compare des transcriptions ALTO XML à un témoin de référence et permet de vérifier les leçons sur les fac-similés.

1. Importer et aligner les témoins

  1. Dans Œuvre et témoins, sélectionnez les fichiers ALTO du témoin de référence et donnez-lui un nom. Utilisez Ajouter un témoin pour chaque autre témoin. Vous pouvez comparer jusqu’à dix témoins, référence comprise. Utilisez Retirer le témoin pour l’enlever du projet.
  2. Pour consulter l’écriture avec le texte, sélectionnez les images des pages de chaque témoin. Des noms de fichiers correspondants facilitent l’association avec les fichiers ALTO.
  3. Le premier alignement démarre dès que deux témoins sont disponibles. Le bouton d’alignement permet de relancer le calcul. Sauvegardez une copie du projet avant de relancer le calcul si des leçons ont déjà été révisées.

2. Réviser la collation

  • Paire affiche la référence et un témoin sélectionné. Tous les témoins garde la référence à gauche et permet de faire défiler les autres témoins. Ligne par ligne affiche une unité à la fois, avec des flèches pour naviguer.
  • Le jaune indique une variante à examiner. Conserver la fait passer au vert et l’inclut dans l’apparat TEI. Écarter la grise et la barre. Passez à la variante suivante à examiner pour poursuivre la révision.
  • Les commandes de modification du texte et de l’alignement permettent de corriger une leçon, de scinder un fragment ou de le déplacer. Si une leçon comporte plusieurs fragments, ouvrez Détails de la révision. Une coche apparaît lorsque toutes les variantes de la fiche du témoin ont été traitées.
  • Cliquez sur le recadrage d’un fac-similé pour afficher la page entière. Un contour rouge repère la ligne si les coordonnées ALTO sont disponibles.

3. Enregistrer ou exporter

  • Enregistrez le projet pour télécharger un fichier de session que vous pourrez rouvrir dans Varians. Le fichier conserve le travail et les noms des images locales, que vous pouvez sélectionner à nouveau après l’ouverture. Un rafraîchissement du même onglet rétablit normalement la session locale.
  • Dans le menu d’export TEI, choisissez la prose, la poésie ou le théâtre pour tout le texte ou par intervalles. Dans Lignes de titre, sélectionnez les lignes de référence à encoder en <head>.
  • L’export JSON permet de réutiliser les leçons, les références ALTO et les décisions de révision dans d’autres outils.

Varians confronta trascrizioni ALTO XML con un testimone di riferimento e permette di verificare le letture sui facsimili.

1. Importa e allinea i testimoni

  1. In Opera e testimoni, seleziona i file ALTO del riferimento e assegna un nome al testimone. Usa Aggiungi un testimone per ciascun altro testimone. Puoi confrontarne fino a dieci, riferimento incluso. Usa Rimuovi testimone per toglierne uno dal progetto.
  2. Per consultare la scrittura insieme al testo, seleziona le immagini delle pagine di ciascun testimone. I nomi di file corrispondenti aiutano Varians ad associare le immagini agli ALTO.
  3. Il primo allineamento parte quando sono disponibili il riferimento e almeno un altro testimone. Usa il pulsante di allineamento per ricalcolare. Se hai già preso decisioni editoriali, salva una copia del progetto prima del ricalcolo.

2. Rivedi la collazione

  • Coppia mostra il riferimento e un testimone selezionato. Tutti i testimoni tiene il riferimento a sinistra e permette di scorrere gli altri. Riga per riga mostra una sola unità alla volta e usa le frecce per passare alla precedente o alla successiva.
  • Il giallo segnala una variante da rivedere. Conserva la colora di verde e la include nell’apparato TEI. Ignora la rende grigia e barrata. Passa alla prossima variante da esaminare per proseguire.
  • Usa i comandi di modifica del testo e dell’allineamento per correggere una lettura, dividere un frammento o spostarlo. Quando una lettura comprende più frammenti, apri Dettagli della revisione. La spunta appare quando hai deciso tutte le varianti della scheda del testimone.
  • Clicca sul ritaglio del facsimile per vedere la pagina intera. Se l’ALTO contiene le coordinate, un contorno rosso individua la riga.

3. Salva o esporta

  • Salva progetto scarica un file da riaprire con Apri progetto. Il file conserva il lavoro e i nomi delle immagini locali, che puoi selezionare di nuovo quando lo riapri. Ricaricando la stessa scheda del browser, normalmente si ripristina la sessione locale.
  • Nel menu di esportazione TEI, scegli prosa, poesia o teatro per l’intero testo o per intervalli. In Righe di titolo, seleziona le righe del riferimento da esportare come <head>.
  • Usa l’esportazione JSON per riutilizzare letture, riferimenti ALTO e decisioni editoriali in altri strumenti.
