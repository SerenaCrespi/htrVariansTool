# Commit messages

Use the user's fixed vocabulary for every commit message, followed by a space
and a concise description:

- `[edit]` — editorial changes, such as corrected manuscript words or readings.
- `[func]` — additional functionality.
- `[refa]` — refactoring.
- `[fix]` — bug fixes.

Choose the prefix matching the main purpose of the change. Use these exact
spellings; do not substitute other commit prefixes.
